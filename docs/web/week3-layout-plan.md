#2. เครื่องมือ CSS ที่เลือกใช้และเหตุผล

ส่วนหัว (`<header>`) ใช้ Flexbox:** เพราะต้องการจัดวางกลุ่มเนื้อหาใน แนวนอน เพื่อดันชื่อร้านไปชิดซ้ายและเมนูไปชิดขวา 
รายการสินค้า (`#catalog`) ใช้ CSS Grid:** เพราะต้องการควบคุมแบบตาราง 2 มิติ เพื่อกำหนดจำนวนคอลัมน์ได้ชัดเจน 
แบบฟอร์ม (`form`) ใช้ Flexbox:** เพราะต้องการจัดเรียงกลุ่มช่องกรอกข้อมูล  และปุ่มกดให้เรียงต่อกันอย่างเป็นระเบียบ
